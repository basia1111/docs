Welcome! This portal covers the **Cleeng API 3.1** — the subscriber
management and monetization platform.

## What you can build

- **Customers** — create and manage accounts, look up identities,
  correlate users with your CRM via external IDs
- **Offers & orders** — subscriptions, passes, and one-time purchases,
  with coupons and per-country pricing
- **Payments** — capture, refund, and reject payments
- **Subscriptions** — the full lifecycle: activate, cancel, pause,
  resume, and switch between plans
- **Entitlements** — check whether a customer has active access to any offer

## Start here

1. Read [About the Cleeng API](/guides/about-the-api) for authentication
   and core concepts.
2. Browse the API reference — start with the **Concepts** section before
   diving into endpoints.
3. Check [What's new](/whats-new) for recent changes.

<Warning>
All endpoints require a publisher token. Never expose tokens in
client-side code.
</Warning>
